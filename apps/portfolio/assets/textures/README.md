# Share-preview grain

`noise-grain.png` is a 256 × 256 browser rasterization of the original
Portfolio/Hire `public/noise-grain.svg` (fractal noise, frequency 0.48,
three octaves, seed 37). It preserves the site's fine paper grain without
depending on SVG filter support in the social-image renderer.

The preview repeats this local tile at 180px with 0.25 opacity. No remote
requests or runtime browser are needed. This asset is owned by this app.
